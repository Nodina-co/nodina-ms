# Prometheus notes: feedback for the next version

**These are feedback notes for the next version of `PROMETHEUS.md`.** They
are not instructions and not part of the method; no agent should act on
them. They are a running log of what felt clunky, confusing, or wrong
while using the current version on a real site. When there are enough,
they get worked into a new version of the file, and each fix then reaches
every site through "foundation updated".

Current foundation version these notes are against: **2026-09-27** (see the
top of `PROMETHEUS.md`).

This file stays in this repo. It is not copied into site repos.

## How to add a note

One line is enough. Newest at the top of the log. If you remember, add:

- **Site**: which site you were running it on
- **Phase**: where you were (0 intake, 1 audit, a content session, the Terraform report…)
- **What happened**: what it did, or what you had to do
- **What you expected**: optional, if it isn't obvious

Rough is fine. "Phase 0 asked me 10 things it could have read off the
site" is a perfectly good note.
